# Hướng dẫn quy trình làm việc trên demo_web

## 1. Quy ước tạo nhánh (Branch)
- Không code trực tiếp trên nhánh `main`.
- Khi bắt đầu làm một tính năng hoặc bài học, hãy tạo nhánh mới từ `main` với tên theo chuẩn: `feat/tên-chức-năng` (Ví dụ: `feat/sap-xep`, `feat/tim-kiem`).
- Dữ liệu (câu hỏi, thuật ngữ): `data/tên-việc`
- Tài liệu, test case: `docs/tên-việc`
- Sửa lỗi: `fix/tên-lỗi`

## 2. Quy trình nộp bài (Pull Request)
- Sau khi hoàn thành code trên nhánh của mình, đẩy code lên GitHub.
- Bấm **Compare & pull request** để tạo PR vào nhánh `main`.
- Cần ít nhất **1 thành viên khác duyệt (Approve)** trước khi được phép Merge vào `main`.
